# TV / 投影仪 / 手机

Android TV 客户端是一个播放器壳 + 端上原生播放器 + 本地执行环境。
同一个 APK 也能装进**安卓手机 / 平板**（触屏操作，布局自动切竖屏）。

> 不确定装哪个？先看 [快速开始 · 路线选择](/guide/quick-start#路线选择)。

::: tip iPhone / iPad 装不了这个 APK
iOS 有独立客户端（未签名 IPA，自签安装），见 [iPhone / iPad](/guide/ios)；
不想装 App 就用 Safari 打开 Web 版，步骤见 [Web / Docker](/guide/web-docker#在-iphone-和-ipad-上)。
:::

## 装好它

从 [Releases](https://github.com/upchr/meow/releases) 下载 `meow-TV-<版本>.apk`，任选一种装法：

| 方式 | 步骤 |
|---|---|
| U 盘 | 拷到 U 盘，用电视的文件管理器安装 |
| adb | `adb install -r meow-TV-<版本>.apk` |
| 手机 / 平板 | 直接安装同一个 APK（文件管理器点开，或 `adb install`） |

最低 Android 8.0（API 26），投影仪常见的 Android 9 / armeabi-v7a 能装
（32 位低端机的限制见页尾）。本项目不投应用市场，只提供 APK。

## 装好之后

::: tip 接下来：导入源包
装好只是有了「播放器」，站点（搜索 / 详情 / 播放地址）来自源包；导入后首页才有内容。
两种方式任选：本机执行（电视自己读源包）或连后端（电视只当播放器）。
:::

### 方式一：本机执行（推荐，零依赖）

设置 →「本机执行」→「配置地址」→ 填入源包 `config.all.json` 的 URL，
**点「导入到本机」**（只填不点不会导入）→ 返回首页等待站点加载。要求：

- 配置地址必须电视能访问到（不要写 `127.0.0.1`）
- 源包要是**电视版**：导入后站点全红，多半拿到的是电脑版格式，换电视版，或在电脑上起后端后改用「方式二：连后端」
- 本机执行只收电视能直接跑的源；JS 源（`.js`）与 CMS 直连站要走「连后端」
- 首启会自动装内置兜底站——**看到站点不等于你的源包导入成功**，核对站点数

::: details 技术细节（排查用）
- 顶层 `spider` 必须是 dex 形态（ZIP 内含 `classes.dex`）；class 形态 Android 读不了
- 站点级 `jar` 可省略（回退顶层 `spider`），写了也必须是 dex
- `csp_` 开头的站点属于「电视能直接跑」这一类
:::

源包本身怎么准备见 [导入源包](/guide/source-pack)。

### 方式二：连后端（电视只当播放器）

对电视性能要求最低，源包只维护一份。先在局域网机器上起 [Docker 后端](/guide/web-docker)
或 PC 后端，设置 →「后端地址」→ 填 `http://<主机IP>:30011`（PC 默认 9979），
后端设了令牌就一起填。要点见 [局域网访问与令牌](/guide/web-docker#局域网访问与令牌)。

装好后的首页长这样（电视横屏，顶栏 + 分类胶囊 + 海报墙，焦点停在分类胶囊上）：

![电视上的横屏首页：顶栏（直播 / 片库 / 收藏 / 历史 / AI / 设置）、分类胶囊与海报墙，焦点停在分类胶囊上](/screenshots/tv.png)

### 手机 / 平板（触屏操作）

同一个 APK 直接装在安卓手机或平板上（Android 8.0+）就是一台触屏客户端：
首页、搜索、播放、弹幕与电视版一致，布局自动切竖屏，底部是「首页 / 直播 / AI / 设置 / 我的」导航。

![安卓手机上的 TV 版：顶栏站点与搜索、分类胶囊、海报墙与底部导航](/screenshots/android-phone.png)

触屏和遥控器不同（遥控器按键表见 [播放与弹幕 · 遥控器操作](/guide/playback#遥控器操作)）：

- 单击画面只呼出 / 收起控制栏
- 双击左 / 右 1/3 快退 / 快进 ±10 秒，双击中区暂停 / 继续
- 长按左 / 右 1/3 是 2× 快退 / 快进（只在播放中生效）
- 直播页用底栏的「频道 / 上一个 / 下一个」换台

播放页左上角有屏幕内的「返回」按钮，竖屏和普通横屏都显示（1.2.16 起恢复）；
大屏横屏电视上仍隐藏，用遥控器的「返回」。

::: details 扫码配置（不用在电视上敲遥控器）

手机扫码可以把**后端地址 + 配置地址**一次推给电视。入口在设置页「扫码填写」（弹层标题「手机扫码填写」）：

- 页面显示当前访问令牌，需要时手填
- 推送只把地址写进电视设置；配置本身仍要在电视上点「导入到本机」才会生效，不用重启

:::

::: details 运行时模块（Node / Python 运行时 · 弹幕组件）

TV 的弹幕与脚本源走运行时模块（独立 APK：Node 跑在单独的 `:node` 进程，Python 跑在 Chaquopy 进程）。
设置 →「运行时模块」：先装 Node 运行时（自动识别架构），再装弹幕组件（模块没装时按钮是灰的）；
有 `.py` 源还要装 Python 运行时。
组件说明、版本线与清单校验见 [TV 运行时模块](/ecosystem/runtime-module)。

:::

## 播不动 / 没声音

电视的 WebView 只带基础解码器。遇到 MKV、AC3 / EAC3 / DTS 这类无声音轨，或提示「编码不支持」：

1. 点错误页或控制栏的「用原生播放器打开」——页内原生播放器走系统解码，支持更多容器与音轨；
2. 或者改用转码：要求后端带 ffmpeg（Docker 镜像与 PC 插件自带）。

两种方式都失败时，多半是源站这一集本身有问题，换线路再试。

## 出问题

| 症状 | 先查什么 |
|---|---|
| 装了打不开 / 闪退 | 架构是否匹配（投影仪常见 armeabi-v7a）；Android 版本是否 ≥ 8.0 |
| 配置导入成功但站点全红 | 源包是不是电视版（见上方说明）；地址电视能不能打开 |
| 一直「正在加载」 | 配置地址电视能不能访问；换手机热点验证一次 |
| 能搜不能播 | 源站地址绑客户端 IP 或已过期，换线路试试 |
| 遥控器进不了地址输入框 | 改用扫码推送，或先用后端模式在手机/电脑上配置 |
| 播放卡顿 | 电视解码能力有限，降低画质或换线路；见 [播放与弹幕](/guide/playback) |

::: warning 投影仪（armeabi-v7a）的已知问题
低端 32 位设备上，聚合搜索并发过高可能把进程打崩。
这不是配置问题，属于端上资源限制，详见 [已知限制](/reference/limits)。
:::
